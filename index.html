API Reference

Docs for Every Method

Get help with the specific scrolling methods you override and call, with our API docs.

applyBoundaryConditions(ScrollMetrics position, double value)docs →

Decides how much of a proposed scroll offset is refused at the edges. Return 0.0 to let the content move freely.

double — the overscroll to hand back; 0.0 accepts the whole move
createBallisticSimulation(ScrollMetrics position, double velocity)docs →

Describes what the position does after the finger lifts: a fling, a spring back, a snap, or nothing at all.

Simulation? — null means the position goes idle where it is
performLayout()docs →

Reads the SliverConstraints handed down by the viewport and answers with a SliverGeometry. Must set geometry before returning.

void — called by the viewport once per sliver, per layout attempt
